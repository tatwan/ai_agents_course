# Bonus B4 resources

`labB4_crew.mmd` is the source for `labB4_crew.png`. Ink nodes show the model's work; lime nodes show Python coordination, lookup operations and the recommendation check. The context arrow carries the invoice task's typed output to support.

The diagram's export command is recorded in its source. The notebook embeds the PNG so it works in front ends that do not render Mermaid.

The lab reads the repository's [Chinook database](../../../data/README.md) in place, with a read-only SQLite connection. It ships no new customer dataset. The refund-request flag is a toy teaching input, and the crew has no payment tool.
